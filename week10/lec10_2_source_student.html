Where a Rule Belongs, in a Skill, an Agent or a Knowledge File
Duration: 75 minutes · Platform: Hokie AI · Submission: The regular Hokie AI thread, holding the student's test log and the reflection, exported as a .zip and uploaded to Canvas before leaving class · Lecture Mode: consolidation
Learning Objectives

By the end of this lecture, students will be able to:

  1. Predict, then observe, which instruction wins when a skill disagrees with an agent's instructions or with a typed request.
  2. Describe what happens when two skills cover the same request and disagree.
  3. Run one benchmark skill against a shared agent and record, point by point, which instruction shaped the reply.
  4. Place a business rule in an agent's instructions, a skill, a script or a knowledge file, and give the reason from what the tests showed.
Section 1 of 5
INTRODUCTION
📋 Note for Students

On Tuesday you built a skill and saw that its description determines where it loads. Today the question is what happens when instructions disagree. A skill can say one thing, an agent's instructions another, and the message you type a third. Before you see any result, you predict which one wins.

Three kinds of instruction can reach the same reply. The message you type applies to one request. An agent's instructions apply to every conversation with that agent. A skill applies wherever its description matches. Whether it also loads inside an agent is one of today's tests. When the three agree, nothing needs deciding. Today they disagree on purpose.

A useful way to think about it comes from programming, where a variable defined close to where it is used hides a variable of the same name defined farther away. By that idea, the message you just typed should beat an agent's instructions, and both should beat a skill that sits in your account for every conversation. The demonstration tests that idea.

## Refund amounts

When an email mentions a refund for a late shipment, compute the refund with this function and state the amount it returns.

```python
def late_refund(order_total, days_late):
    rate = min(0.05 * days_late, 0.25)
    return round(order_total * rate, 2)
```
The right refund for this request is 82.50 dollars.
