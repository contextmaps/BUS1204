Learning Objectives

By the end of this progress report, each team will be able to:

  1. Build its business's two agent system on one Google Sheet from a design file: a state tab both agents read, a Requests tab, and a script from a Hokie AI prompt.
  2. Read the comments of the script and explain what its lines do with the sheet, and judge a schema Hokie AI writes against a tested one.
  3. Give the customer agent a tool that adds requests and the staff agent tools that list them, check live data and record the manager's decisions after the manager confirms.
  4. Run a full loop from a customer's request to the manager's decision and the change in the sheet, and judge what to change.
