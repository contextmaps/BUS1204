Learning Objectives

By the end of this part, students will be able to:

  1. Turn a client's rules, written in plain words, into a Python script with Hokie AI, save it as a .py file and install it on an agent that runs it with Code Interpreter.
  2. Trace every input in a script's printed receipt to its source, and check the receipt against a live service and an answer key.
  3. Describe a plot in words and say what it shows that the numbers do not.
  4. Sort a client's change request into what the client approved, what the builder changes to carry it out, and what reached the builder without the client's approval.
  5. Rerun the same questions after a change and tell a change the builder made from a change in the live data.

Class material
The script request
Write a Python script named project_savings.py for the Larkspur Investment Club, a made up student club that helps first-year students think about saving and investing. A club agent will run the script with Code Interpreter. Use only the Python standard library and matplotlib.

The script defines one function, project_savings, with these inputs: start_amount in dollars, monthly_deposit in dollars, years as a whole number, treasury_rate as an annual percent, treasury_date as YYYY-MM-DD, certificate_rate as an annual percent, and stock_return as an annual percent.

The rules.
1. There are three options: "Savings at the Treasury Bills rate" at treasury_rate, "Certificate" at certificate_rate, and "Stock index fund, assumed" at stock_return.
2. For each option, start with start_amount. Each month, first add one month of interest, the annual percent divided by 12, then add the monthly deposit. Repeat for 12 times years months.
3. Total deposited is start_amount plus monthly_deposit times 12 times years.
4. Round money to cents only when printing.

First print every input on its own line, with where each rate came from: the treasury_rate as the Treasury Bills average with its date, the certificate_rate as the club rate sheet, and the stock_return as the club board assumption. Then print, for each option, its name, its rate, its final balance and its growth over the total deposited. Then print the total deposited. Then print this note exactly: Education, not advice. These projections use fixed rates. Real savings rates change, and stock returns vary from year to year and can be negative.

Then draw one plot of the balance at the end of each year, from year 0 to the last year, for the three options, with a dashed line for the total deposited. Mark the x axis in whole years and label it years, label the y axis balance in dollars, title it Larkspur Investment Club savings projection, and put each option's name and rate in the legend. Save it as projection.png and print plot saved as projection.png.

At the bottom, under if __name__ == "__main__":, run one example only when the script is started with the argument --example, and do nothing otherwise: start_amount 500, monthly_deposit 100, years 4, treasury_rate 4.10 dated 2026-09-30, certificate_rate 3.75, stock_return 7.0.
