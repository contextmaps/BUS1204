A Club's Assistant on Live Treasury and Market Data
Platform: Hokie AI · Submission: The chat with the student's Larkspur Club Assistant, exported as a .zip and uploaded to Canvas
Learning Objectives

By the end of this part, students will be able to:

  1. Build an agent for a new client from given instructions, a knowledge file and three live API Calls, each with a link to its documentation.
  2. Check every live answer by reading what was sent in Tool Calls, opening the URI from Execution Log Data in a browser, and comparing the service's value with the agent's.
  3. Find in a service's documentation what a number means, how often it is published and which parameters a call can carry.
  4. Compare two sources for the same number on the same date, and tell a difference in sources from a difference in dates.
  5. Judge when an answer that matches its source can still mislead the person who asked.

In case two the market rate joins the Treasury's official rate, and you find out how much of the difference between two sources comes from their dates.
